# 03 — 美术：3 个英雄（身体 + 武器）、风格锚点

**What to build:** 用 02 的管线生成弓手、法师、骑士。先出完整角色图，用户挑一张最能代表整套风格的作为**风格锚点**；再用锚点重出另外两个（保证一致），最后基于每个完整角色图编辑出“不拿武器的身体”和“单独的武器”。

**Blocked by:** 02

**Status:** ready-for-agent（中间有一步需要用户挑锚点）

- [ ] 三个英雄的完整角色图各出 3–4 张候选，拼成对比图用 Preview 打开给用户挑；用户选定风格锚点（记进 `art/style.md`）
- [ ] 用锚点作参考，重出不一致的英雄，直到三个放在一起风格统一（再给用户确认一次）
- [ ] 每个英雄编辑出 `body`（同一个角色，手里没有武器，姿势便于武器叠上去）和 `weapon`（单独的武器，方向统一朝上或朝右，标出握持点）
- [ ] 每个英雄在游戏里的拼法：武器的挂点和旋转中心写进数据（`heroes.ts`），在浏览器里拼出来、挥动一次确认对得上
- [ ] 打进 `heroes` 图集；显示尺寸约 140 像素高（存 2 倍）
- [ ] 不满意的素材手工修（PS / Photopea），修过的原图标注出来
