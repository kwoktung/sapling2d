# 04 — 骨架：场地、槽位、随机路线、波次、弓手

**What to build:** `examples/hero-guard` 从 `templates/game` 起步，做出最小可玩的一局（全部占位图，美术到位后替换）：
草地占位背景、顶部出生点、底部城门和底线；6 个槽位；怪物（史莱姆）沿随机 `Curve2D` 路线下来，出现时路线虚线闪一下；弓手站在槽位上自动射箭；20 波、20 条命。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 目录和脚本照 `examples/towerdefense`（`dev`、`build:wechat`、`log-server`、`check`）；`AGENTS.md` 写清楚结构
- [ ] 数值全部在 `config.ts`；英雄基础数值、怪物数值用 spec 的起始值

- [ ] 随机路线：沿用灰盒原型的控制点生成方式，用 `Curve2D.catmullRom`；怪物出现时路线以虚线（一串小点精灵）显示约 1 秒再淡出

- [ ] 史莱姆：走路的上下弹跳 + 挤压拉伸、按方向翻转、受击 `flash`、头顶血条；越过底线扣命

- [ ] 怪物 y 排序（`zIndex = y`）；伤害飘字、命中火花、击杀碎片（灰盒原型的做法）
- [ ] 无头测试：路线从上到下、拖动和交换、弓手只打射程内离城门最近的、漏怪扣命、命用完失败、20 波打完胜利
