# 05 — 经验、升级三选一、技能树；弓手的 3 条分支

**What to build:** 击杀得经验，升级时暂停并弹出三选一；技能树的数据模型（英雄 × 分支 × 4 级，第 4 级质变）；弓手的 多重箭 / 狙击 / 毒箭 三条分支全部实现。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 经验和等级：升级所需 `10 + 6 × 等级`；界面上有经验条和等级
- [ ] 升级时 `tree.paused = true`（界面层 `processMode: 'always'`），弹出 3 张卡片（暂用纯色占位，13 换成九宫格边框）；选完继续。连升多级时依次弹出
- [ ] 技能树数据（纯数据文件，不依赖引擎）：每个节点有 `hero`、`branch`、`level`、名字、描述、效果；效果作用在英雄的运行时数值或行为开关上
- [ ] 抽卡：从已上场英雄各分支的下一级里随机抽（`tree.rng`），点满的分支不再出现；（通用选项在 11 加入同一个池子）
- [ ] 弓手三条分支按 spec 的表实现，包括三个质变：穿透箭、每第 5 箭爆头（无视护甲）、中毒死亡时毒雾扩散
- [ ] 卡片上显示英雄头像（占位）、分支名、等级（第几级 / 质变）、效果描述
- [ ] 无头测试：经验和升级阈值、暂停和恢复、抽卡不重复且只出下一级、点满后不再出现、每个弓手节点的效果（多重箭的目标数、暴击、中毒叠层、穿透、爆头、毒雾）
