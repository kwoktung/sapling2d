# 16 — 站位分区、自动走位、英雄血条、阵亡复活

**What to build:** 去掉槽位，英雄按定位在自己的区域里全自动走位；英雄有血条，地面怪会离开路线围攻附近的英雄；英雄阵亡变成墓碑，15 秒后原地复活。规则见 spec 的“站位和走位”。

**Blocked by:** 14

**Status:** ready-for-agent

- [ ] 去掉 `Slot`、拖动换位、放置状态（`placing`）；选完英雄卡直接出现在区域的默认位置
- [ ] 区域：近战中上（横向中间 70%，纵向 30%–60%），远程左下 / 右下（纵向 0–30%，先上场的去左下）；数值进 `config.ts`；选英雄卡上用小图示意区域
- [ ] 走位：骑士追区域里剩余路程最短的怪、没怪回中心（140 像素/秒）；远程站固定点，射程内没目标时往最近的怪挪、不出区域（90 像素/秒）
- [ ] 怪物仇恨：地面怪 110 像素内看到活着的英雄就离开路线过去打（人数不限）；英雄阵亡或走远就回到路线继续走；蝙蝠、幽灵不理英雄；攻击时朝英雄扑一下
- [ ] 怪物攻击数值（spec 的表，精英 ×2）；英雄血量和骑士护甲；脱战 3 秒后每秒回 5%
- [ ] 英雄受击闪白、飘红字；头顶血条（满血隐藏）
- [ ] 阵亡：变墓碑（美术管线生成一张墓碑）+ 15 秒倒计时；不攻击、不能放大招（能量保留），大招按钮变灰显示倒计时；复活回满血、1 秒无敌
- [ ] 嘲讽改成强制半径 120 内的怪来打骑士；冲锋从当前位置出发、回到原位；击退后怪重新走回英雄身边
- [ ] 技能树：守护分支改成 血量 +30% / 斩击吸血 15% / 受到的伤害 −15% / 嘲讽光环；眩晕移进重击 Lv3（20% 几率眩晕 1 秒）；新通用选项“坚韧”全体英雄血量 +20%（配图标）
- [ ] 音效：英雄受击、英雄阵亡（从已下载的 CC0 包里挑，补进 CREDITS.md）
- [ ] 测试：分区和出生点、骑士追怪和回中心、远程不出区域、仇恨和回到路线、飞行怪不理英雄、受伤 / 回血 / 阵亡 / 复活 / 无敌、阵亡时不能放大招、嘲讽、技能树新节点；改掉依赖槽位的旧测试
