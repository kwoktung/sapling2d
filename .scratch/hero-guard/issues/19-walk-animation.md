# 19 — 走路动画（序列帧）

**What to build:** 英雄和有脚的怪物走路时腿在动：用 Gemini 按现有角色图生成 4 帧走路序列，美术管线切帧、抠图、对齐脚底，游戏里用 `AnimatedSprite2D` 播放。设计见 2026-10-10 的拷问（结论如下）。

**Blocked by:** 16

**Status:** done (2026-10-10)

**范围**
- 做：弓手、法师、骑士、骷髅战士、哥布林萨满。
- 第二批（可选，这次不做）：骷髅巫妖的袍子摆动、蝙蝠扇翅膀。
- 不做：史莱姆、小史莱姆、分裂史莱姆、史莱姆王、幽灵（保留弹跳）。

**任务**
- [x] 美术管线：支持“横排 N 帧”的素材——生成一张 N 帧横排图，按格切开，逐帧抠图，用所有帧的并集裁边（脚底对齐、锚点一致），帧名 `<id>_0` … `<id>_<N-1>` 打进图集
- [x] **先做骷髅**：出 3 套候选，Preview 里并排给用户看（每套 4 帧 + 脚底线）。验收：4 帧比例和花纹一致、脚底在同一条线、循环看得出迈步。都不行就改程序化摇摆（身体左右摇几度 + 上下轻颠），本工单其余角色也照此处理
- [x] 通过后铺开到萨满和 3 个英雄。英雄的帧要求只有腿在动、上半身和手臂保持原姿势（武器挂点不变）
- [x] 播放：4 帧循环，播放速度按实际移动速度换算（减速变慢、冰冻 / 眩晕停住），脚不打滑；停下时（站着、攻击中、被控制）停在第 1 帧
- [x] 站着时的呼吸：身体轻微上下伸缩（程序化，所有英雄和有脚的怪）
- [x] 有脚的怪不再弹跳，改成走路帧 + 每步轻微上下颠；史莱姆、幽灵照旧弹跳
- [x] 测试（动画随移动播放 / 停下回第 1 帧 / 速度跟移动速度）、AGENTS.md、浏览器截图，需要的话真机看一眼

## Comments

**实现（2026-10-10）：**

- 管线：`frames` / `mirror`；按连通块分帧（第一版按“最少不透明像素的列”切，切掉了骷髅的刀尖——刀身细，那一列像素也少）；抠图前从四角取实际背景色（这批图的背景是偏暗的品红，被腿围住的小块背景之前没抠掉）。
- 挑定：骷髅候选 2、弓手 2（镜像翻回）、法师 3、骑士 2；萨满第一轮三套脚尖一会儿朝前一会儿朝右，第二轮提示词加了“脚朝走路方向”，选了候选 5。原图都在 `art/refs/walk_*.jpg`，参考图也固定进了 refs（`<hero>_body.jpg`、`enemy_shaman.jpg`）。
- 播放：不用 fps，按走过的距离换帧（英雄每 12 像素、怪每 9 像素 × 身高比例一帧），减速自然变慢、停下就停，追人、回路线、击退都对得上；一步（两帧）轻颠一次；站着第 1 帧 + 呼吸。用的是引擎 `AnimatedSprite2D` 的 `frame` / `frameCount`，没改引擎。
- 英雄站着也显示走路第 1 帧（不再用静态身体图），和静态图叠在一起看手的位置基本重合，武器挂点没改。选英雄卡和大招按钮还用静态身体图。
- 包体：图片 + 音频 1.8 MB。
