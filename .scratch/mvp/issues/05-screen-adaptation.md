# 05 — 屏幕适配

**What to build:** 游戏用设计分辨率来写，在任何屏幕尺寸上都能正确缩放显示。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 可以配置设计分辨率（比如 750×1334）和拉伸模式 `expand`（默认）或 `keep`
- [ ] `expand` 模式下，可视区域会沿长边扩展，引擎暴露当前可视矩形
- [ ] 渲染分辨率等于 DPR，上限为 2
- [ ] 暴露换算到设计坐标后的安全区
- [ ] 浏览器窗口 resize 时重新计算布局，并触发一个信号
- [ ] 无头模式下可以配置屏幕尺寸、DPR 和安全区，有测试覆盖坐标换算
