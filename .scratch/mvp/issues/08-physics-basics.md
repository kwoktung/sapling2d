# 08 — 物理基础：刚体下落与堆叠

**What to build:** 用 planck 做物理（见 ADR 0005），刚体会下落并堆叠在静态地面上。浏览器里能看到效果，无头模式下的运行结果是确定的。

**Blocked by:** 03, 04

**Status:** ready-for-agent

- [ ] 实现 `RigidBody2D`、`StaticBody2D` 和 `CollisionShape2D`（圆形、矩形）
- [ ] 物理按固定 60Hz 步进，用时间累加器补帧，每帧有补步上限，由引擎驱动 `world.step`
- [ ] 内部按 `pixelsPerMeter`（默认 50，可配置）换算单位；对外一律用像素，重力单位是 px/s²（默认 980）
- [ ] 刚体状态以 planck 为准，每一步物理结束后写回节点；用户设置 position 或 rotation 时，刚体瞬移过去并清空速度
- [ ] 每帧最多补 2 个物理步，超出的时间丢弃（防止没有 JIT 时补帧雪崩，见 spike 报告第 8 节）
- [ ] 速度迭代和位置迭代次数可以配置
- [ ] 用 `node --jitless` 跑性能基准（150 个圆形刚体，记录单步耗时），用来近似 iOS 真机
- [ ] 支持质量、摩擦、弹性、线速度和角速度，以及施加冲量
- [ ] planck 只封装在引擎的物理模块里，用户 API 不暴露它；模块设计上为 kinematic 类型留好位置
- [ ] 无头测试：同一个 seed 和输入跑两次，`dump` 结果完全一致
- [ ] 浏览器示例：点击生成圆球，球会在地面上堆叠起来
