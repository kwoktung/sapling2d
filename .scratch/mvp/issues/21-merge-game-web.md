# 21 — 合成大西瓜（web）

**What to build:** 用 sapling2d 做一个完整可玩的合成类游戏，在浏览器里运行。它就是这个引擎 MVP 的验收标准。

**Blocked by:** 06, 07, 09, 10, 12, 13, 14

**Status:** ready-for-agent

- [ ] 点击或拖拽控制投放位置，松手后投放当前水果，并显示下一个水果的预览
- [ ] 同级水果碰撞后合成为高一级的水果，伴随 Tween 动效和音效；最高级合成时有特殊效果
- [ ] Label 显示计分，最高分存进 Storage
- [ ] 堆过顶线一段时间判定游戏结束，切到结束场景，可以重开
- [ ] 有 BGM，可以静音
- [ ] 无头测试覆盖：投两个同级水果，step 之后断言合成成功、分数增加；超过顶线时判定游戏结束
- [ ] 只使用引擎的公开 API，用不到 `unsafePixi`
