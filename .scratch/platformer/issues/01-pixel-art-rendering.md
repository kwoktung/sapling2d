# 01 — 像素风渲染选项：最近邻采样，绘制位置对齐物理像素

**What to build:** 游戏启动时打开一个像素风选项（暂定 `pixelArt: true`）后，所有贴图用最近邻采样，节点的绘制位置对齐到物理像素。
设备缩放不是整数时（例如 iPhone 横屏约 4.47 倍），像素图不模糊；节点慢速移动时不抖动、不出现半像素的边缘。
节点自己的 `position` 不变，只在绘制时取整，游戏逻辑和无头测试不受影响。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 启动参数里的像素风开关，浏览器和小游戏的 `startGame` 都支持；默认关闭，现有游戏的行为不变
- [ ] 开启后，所有贴图（包括图集的子区域和之后加载的贴图）都用最近邻采样
- [ ] 开启后，绘制时节点的全局位置对齐到物理像素（考虑视口缩放和渲染分辨率），文字（Label）不受影响
- [ ] 渲染同步的测试覆盖：开关打开时采样方式和取整后的位置正确
- [ ] 用一个现有示例在浏览器里对比开和关的效果
- [ ] `llms.txt` 说明这个选项和适用场景
