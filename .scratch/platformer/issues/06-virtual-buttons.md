# 06 — 虚拟按键：屏幕上的触摸区域映射到输入动作

**What to build:** 小游戏没有键盘。游戏可以在屏幕上放按钮（左、右、跳），按住按钮时对应的动作处于按下状态（`isActionPressed('jump')`、`isActionJustPressed('jump')`），
和键盘绑定共用同一个动作名。支持多点触控（一只手按住“右”，另一只手按“跳”），手指滑出按钮或抬起时松开。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 按钮按下 / 松开驱动动作状态，和键盘绑定同一个动作时两者都能触发
- [ ] 多点触控：每个手指独立，同时按住两个按钮都生效
- [ ] 手指滑出按钮、抬起、触摸取消、切到后台时，动作都会松开，不会卡住
- [ ] 按钮的触摸区域可以比贴图大（手指比鼠标粗）
- [ ] 浏览器里鼠标和触摸都能用；小游戏里触摸能用
- [ ] 无头测试可以模拟多点按下和松开
- [ ] 每帧不分配内存
- [ ] `llms.txt` 加示例，说明和 `pointerPress()` 的区别
