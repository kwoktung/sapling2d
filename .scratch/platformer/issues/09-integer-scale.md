# 09 — 视口整数倍缩放（像素风）

**What to build:** 像素风游戏可以让设计分辨率只按整数倍放大到屏幕（按物理像素算：例如 270 高的设计分辨率，在 iPhone 横屏 1206 个物理像素高的屏幕上放大 4 倍，而不是 4.47 倍），
多出来的空间按现有的拉伸模式处理（`expand` 向两侧扩展可见区域，`keep` 留黑边）。这样每个设计像素都是整数个物理像素：
移动中的精灵宽度不再跳动，旋转、缩放时也不会因为顶点对齐而变形，图块不会出现缝（01 的已知代价）。

**Blocked by:** None — can start immediately（和 04 Camera2D 都会改视口的变换，同时做时注意合并）

**Status:** ready-for-agent

- [ ] 视口设置里的整数倍缩放开关，默认关闭，现有游戏的行为不变
- [ ] 缩放倍数按物理像素取整（考虑渲染分辨率，不只是 CSS 像素）；屏幕小于设计分辨率时退回到不取整的缩放，并在开发模式下警告
- [ ] `expand` / `keep` 两种模式下可见区域、安全区域、`screenToDesign` 都正确
- [ ] 视口变换（缩放和偏移）都是整数物理像素
- [ ] 无头测试覆盖几种常见屏幕尺寸（包括 iPhone 横屏）
- [ ] `llms.txt` 在像素风一节推荐和 `pixelArt` 一起用
