# 02 — KnifeCollider：刀碰刀、刀碰身体（游戏内模块）

**What to build:** `examples/spinblade/src/` 下的 `KnifeCollider`，负责这个游戏的刀碰撞判定（有意不进引擎，原因见 spec）。

- 刀是旋转矩形（OBB），身体是圆。矩形和矩形用分离轴定理，矩形和圆用最近点检测；先用外接圆粗筛。
- 按刀圈分组：两个刀圈的外接圆不重叠就跳过整组；同一个主人的刀之间不判定。
- 子步：在 `physicsProcess` 里把这一步的刀圈角度变化分成 k 份（k = ⌈相对位移 ÷ 刀宽⌉），每份摆放一次再判定，避免转得快时直接穿过去。
- 结果交给游戏：刀碰刀时两把刀弹开、被打飞落到地上（用 Tween，不用刚体），可以被捡起；刀碰到别人的身体时扣血。

## Comments

**实现（2026-10-09）：**

- `src/KnifeCollider.ts`：纯几何，不依赖引擎（可以单独测试、跑基准）。角色实现 `RingBody`（这一步开始和结束时的位置、刀圈角度，刀圈半径、刀数、身体半径），刀的位置在任意子步时刻按角度重建。
- **防穿透的做法和工单原文不同**：原文是“按子步摆放再判定”，那样仍可能漏掉擦边的碰撞。实际做法是在每个子步的**中点**采样，并把形状膨胀“半个子步里任何一点的最大位移”（刀：平移 + 转角 × (刀圈半径 + 刀的外接圆半径)；身体：平移）。物体在子步里的任何位置都在中点处膨胀后的形状里，所以这一步里任何时刻重叠过都一定会被发现。子步数 k = ⌈最大位移 ÷ 半个刀宽⌉（上限 8），膨胀量最多约 1/4 刀宽。
  - 一开始按 t = 1/k, 2/k, …, 1 采样，测试发现每一步开头的 [0, 1/(2k)) 没被覆盖（刀砍身体漏报），改成中点采样。
- 粗筛：角色对按“这一步的中点 + 整步位移 + 最大膨胀”的外接圆筛一次；每个子步再按两个刀圈的外接圆、两把刀的外接圆筛。刀的方向用复数乘法递推，每个角色每个子步只调两次三角函数。
- 同一子步里先判刀碰刀、再判刀砍身体；碰过刀的刀这一步不再参与；同一把刀砍同一个角色一步只报告一次。回调里只记录，`detect` 之后场地再打飞刀、扣血（下标不会错位）。
- 游戏接入：场地的 `physicsProcess` 按顺序驱动所有角色的 `step`（移动、转刀圈），再判定碰撞，最后推挤和捡刀；`Fighter` 不再覆写 `physicsProcess`，顺序不依赖节点遍历顺序。
  - 打飞：刀沿刀尖方向飞 150px、边飞边转（Tween，0.35 秒），落地后才能捡。落点从主人的中心（一定在空地上）往外找，碰到墙之前的最后一个空地（刀圈里的刀可能本来就压在墙上，从刀的位置开始找会落进墙里，测试发现过）。
  - 扣血：每把刀砍中后 0.5 秒内不再造成伤害（`hitReadyAt`，按 `tree.time`）；受伤时变红 0.15 秒。血量为 0 时的死亡留给 07。
- 刀圈角度不取模（碰撞判定要用这一步转过的角度），超过 1000 圈时整圈整圈减回来。

**验收（`test/KnifeCollider.test.ts`，对照答案是每步密集采样 400 次、不膨胀）：**

- 1500 个随机场景（两个刀圈各 1–12 把刀，以测试用最高转速 7 rad/s（游戏里的两倍）反向旋转，各自移动最快 360 px/s，刀圈交叉，这一步开始时没有刀重叠）：对照答案里有 234 个碰撞，**漏掉 0 个**。
- 只在步末判定一次（`swept: false`）：漏掉 3 个（约 1.3%），证明子步有效。实际漏判率比开工前估算的低：大部分碰撞的重叠持续时间超过一步。
- 误判上限：报告碰到的场景，把两把刀的半长、半宽各加 1/4 刀宽后，对照答案也都碰到。
- 刀砍身体：500 个场景里对照答案砍到的刀都报告了，没有重复报告。
- 场地测试：刀碰刀后两把刀都被打飞、落地、刀的总数不变；落地的刀能被别人捡起；砍身体扣血且受冷却限制；靠墙时打飞的刀不会落进墙里。
