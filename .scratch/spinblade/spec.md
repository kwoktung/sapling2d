# Spec: examples/spinblade（转刀类玩法）

Status: ready-for-agent
Date: 2026-10-09

参照微信小游戏《转刀大闯关》做一个验证用的示例，用来推动引擎补齐俯视角动作游戏需要的通用能力。和 `platformer` 一样：游戏只用来驱动和验证引擎，
做的过程中发现的引擎问题记成新工单，不在示例里绕过（只有本文“放在游戏里”一节列出的部分是有意留在游戏里的）。

## 玩法

- 竖屏、俯视角。玩家用摇杆移动（浏览器里也可以用 WASD）。
- 角色身边有一圈刀一直在转。地图上散落着刀，捡到后刀圈变大（刀数增加）。
- 两边的刀碰到会互相弹开，刀被打飞、掉在地上，可以被任何人捡走；刀碰到身体就扣血，血量为 0 死亡。
- 关卡按顺序推进：一关、一种普通敌人、一个 Boss。清掉敌人后出现 Boss，打败 Boss 就过关；玩家死亡就重开本关。
- 只做单人关卡模式，不做 .io 联网对战，也不做局外养成。

## 目标

- 一关、一种敌人、一个 Boss，可以从头玩到过关。
- **性能**：同屏约 150 把刀、20 个敌人，iPhone 小游戏（发布构建）稳定 60 fps，用 `game.frameStats` 记录。同时测一次约 500 把刀的情况，只记录数据，不要求达标；
  是否需要空间分桶看测出来的数字再决定。
- 画面：竖屏 750×1334、`expand`；美术先用几何占位图（纯色刀片、圆形角色），放在 `public/assets/`。

## 引擎要补的

按游戏的需要依次做（见“顺序”），每一项都在 `llms.txt` 加示例测试，并在真机上验证一次。

| 工单 | 功能 | 范围 |
|---|---|---|
| 03 | `TouchJoystick` + `Input.getVector` + 动作力度值 | 两种模式 `dynamic`（默认，在指定区域按下的地方出现）/ `fixed`；摇杆把力度写进动作，浏览器里的 WASD 走同一个接口 |
| 04 | `tree.timeScale` | 缩放 `process` 的 dt、物理步、Tween、Timer、`tree.time`；界面也一起受影响（不区分） |
| 05 | `ColorRect` | 纯色矩形（血条、遮罩） |
| 06 | `Particles2D`（精简版） | 一张贴图；一次性爆发 / 持续发射；数量、生命周期、初速度和随机范围、重力、随生命周期变化的缩放和透明度；粒子不是节点，批量渲染 |

**不改引擎，只补文档**：屏幕震动（用 Tween 改 `Camera2D.offset`，写进 `llms.txt` 相机一节）。

## 放在游戏里的（有意不进引擎）

- **`KnifeCollider`**（`examples/spinblade/src/` 下）：刀碰刀、刀碰身体的判定。
  - 刀是**旋转矩形**（OBB）：矩形和矩形用分离轴定理，矩形和圆用最近点检测；先用外接圆粗筛。
  - 按刀圈分组粗筛：两个刀圈的外接圆不重叠就跳过整组。
  - **子步**：刀转得快，相邻两个物理步之间可能直接穿过对方（估算：刀宽 12px，两个刀圈反向时相对位移约 47px/步）。
    在 `physicsProcess` 里把这一步的角度变化分成 k 份（k = ⌈相对位移 ÷ 刀宽⌉，一般 2–4），每份摆放一次再判定。
  - 不用 `HitTester` 的矩形：它的矩形永远轴对齐，不随 rotation 转。
- **刀的摆放**：所有刀都直接挂在场地节点下（不挂在旋转的刀圈节点下），角色每帧按“刀圈角度 + 第几把刀”算出每把刀的 `x`、`y`、`rotation`。
  所有刀都在同一个坐标系里，被打飞、落地、捡起时不用换父节点。
- **身体之间的推挤**：`CharacterBody2D` 只和图块地图碰撞，角色之间会重叠。用 `HitTester` 做圆和圆的组内判定，重叠了就互相推开。
- **地形**：关卡用 Tiled 做，墙和障碍物在图块层里；角色和敌人都是 `CharacterBody2D`（俯视角，没有重力，不用 `isOnFloor`）。这是 `CharacterBody2D` 第一次用在俯视角。

**升级进引擎的条件**：出现第二个需要旋转矩形判定的游戏时，把 `KnifeCollider` 里的 OBB 判定挪进 `HitTester`（可选字段 `hitRotation`，不影响现有游戏），并修订 ADR 0007。

## 顺序

游戏推动引擎：先用现有引擎 + 浏览器键盘搭出可玩的骨架，再按游戏的需要补引擎功能。

1. 01 骨架：场地、移动、刀圈、捡刀、推挤（键盘）
2. 02 `KnifeCollider`：刀碰刀、刀碰身体
3. 03 摇杆 → 04 `timeScale` → 05 `ColorRect` → 06 `Particles2D`（引擎，各自独立，都可以和 01、02 并行）
4. 07 敌人、Boss、关卡流程和打击感（用上 03–06）
5. 08 真机性能和试玩

## 不在范围内

联网 / .io 模式、局外养成和商店、多关卡和关卡选择、正式美术、刀的种类和升级、`Graphics` / `Polygon2D` 之类的通用绘图节点、相机震动 API、`CharacterBody2D` 之间的碰撞。
