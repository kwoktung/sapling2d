# Agent guide for this game

This is a [sapling2d](../../packages/engine/llms.txt) game. **Read `node_modules/sapling2d/llms.txt` (or `packages/engine/llms.txt` in the sapling2d repo) before changing code.**

## Layout

A side-scrolling platformer (one level, like FC Super Mario 1-1), landscape 480×272, pixel art.

- `src/game.ts` — `gameOptions` (entry scene, `GameState` autoload, input actions, design size, `pixelArt`) and the action name registry.
- `src/config.ts` — tuning numbers: player movement and jump, enemy speed, scores, timer.
- `src/assets.ts` — every asset: the Tiled level (`tiledMap`), sprite sheets, button images.
- `src/state.ts` — `GameState` autoload: score, coins and lives survive a level restart.
- `src/scenes/Level.ts` — builds the level from the Tiled map (tile layers + `Entities` object layer: `Spawn`, `Goomba`, `Coin`, `Goal`), scrolls the camera right only, runs player × enemy / coin hit checks with `HitTester`, bumps bricks and question blocks, handles death, time-out and the goal.
- `src/nodes/` — `Mario` and `Goomba` are `CharacterBody2D` (tile collision via `moveAndSlide`); `Coin` / `CoinPop`; `Hud` and `Controls` are `CanvasLayer`s (fixed on screen; `Controls` holds the `TouchScreenButton`s).
- `public/assets/` — generated by `node scripts/gen-assets.mjs`: pixel art from ASCII templates, and the level as Tiled JSON (`levels/1-1.json` + external tileset `levels/tiles.json`). You can open the level in Tiled; if you edit it there, stop regenerating it from the script.
- `test/level.test.ts` — headless flow tests.

Tile collision comes from the tileset's string property `collision` (`solid` / `oneWay`); bricks have `breakable: true`, question blocks `question: "coin"`.

## Workflow

Same as the other examples: test first with `createTestGame` (it reads the real level file from `public/assets`), `pnpm check`, `pnpm dev` for the browser (arrow keys / A-D to move, Space / Up / W / K to jump), `pnpm build:wechat` for the WeChat Mini Game (landscape). On WeChat the game logs `game.frameStats` every 5 seconds (`[perf] …`); build with `SAPLING_LOG_URL` and run `pnpm log-server` to read them.
