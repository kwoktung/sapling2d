# Agent guide for this game

This is a [sapling2d](../../packages/engine/llms.txt) game. **Read `node_modules/sapling2d/llms.txt` (or `packages/engine/llms.txt` in the sapling2d repo) before changing code.**

## Layout

A top-down "spinning knives" brawler (like the WeChat mini game 转刀大闯关), portrait 750×1334. Spec and tickets: `.scratch/spinblade/` at the repo root.

- `src/game.ts` — `gameOptions` (entry scene, input actions) and the action name registry.
- `src/config.ts` — tuning numbers: fighter size, push stiffness, player speed, ring spin / radius / spacing, knife pickup radius, z-order.
- `src/assets.ts` — every asset: the Tiled level (`tiledMap`) and textures.
- `src/scenes/Arena.ts` — builds the arena from the Tiled map (tile layers `Floor` / `Walls` + `Entities` object layer: `Spawn`, `Enemy` (property `knives`), `Knife`). Its `physicsProcess` drives the whole step in order: every fighter's `step` → `KnifeCollider` (clashes knock knives off, body hits deal damage) → push-apart and ground-knife pickup with `HitTester`.
- `src/KnifeCollider.ts` — the game's own knife collision (rotated rectangles, swept with substeps so fast rings never pass through each other). Pure geometry, no engine imports. Deliberately not in the engine; see the header comment for when to move it.
- `src/nodes/Fighter.ts` — base class for `Player` / `Enemy`: a top-down `CharacterBody2D` (no gravity) blocked by wall tiles; owns a knife ring, `hp`.
- `src/nodes/Knife.ts` — a knife: on the ground, flying (just knocked off), or in someone's ring (`owner`).
- `public/assets/` — generated by `node scripts/gen-assets.mjs`: flat placeholder shapes and the level as Tiled JSON (`levels/arena.json` + external tileset `levels/tiles.json`).
- `test/` — headless tests; `test/KnifeCollider.test.ts` checks the collider against a brute-force reference (400 samples per step).
- `bench/` — `pnpm bench` / `pnpm bench:jitless` (no JIT ≈ iOS): collider cost per step.

**All knives are direct children of the arena**, never of the spinning ring: each fighter places its ring knives every physics step (`placeKnives`) from the ring angle, so every knife lives in one coordinate system for hit testing and can drop to the ground or change owner without reparenting. Pushes go through `moveAndSlide` (as extra velocity), so a pushed fighter is still blocked by walls.

## Workflow

Same as the other examples: test first with `createTestGame` (it reads the real level file from `public/assets`), `pnpm check`, `pnpm dev` for the browser (WASD / arrow keys to move), `pnpm build:wechat` for the WeChat Mini Game. On WeChat the game logs `game.frameStats` every 5 seconds (`[perf] …`); build with `SAPLING_LOG_URL` and run `pnpm log-server` to read them.
